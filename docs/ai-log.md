**Rejected / changed from the original proposal:**

- **Item 3's specification is unsound and was not implemented as written.** "Memoize node → element by id + resolved props hash" is right for leaves — and was already implemented in P3 (`getMemoizedLeaf`). Implemented instead on the inputs the whole subtree can see (node identity + `state`/`data`/`theme`/`registry`/`dispatch` identity), which is also cheaper than the `JSON.stringify` the leaf memo does. `src/sdui/tests/core/nodeMemo.test.tsx` fails under the version the prompt asked for.
